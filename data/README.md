# Paper A — machine-readable data

Hartree atomic units; c = 1/α = 137.035999084 (CODATA 2018);
V = −Z e^{−λr}/r (λ = 0 is the point-nucleus Coulomb case); binding
energies are E − c². All four files are verbatim exports of the solver
output (`feast-spectral` repo), not re-typed.

**One exception to the value of c.** `validation_errors.csv` uses
c = 137.0359895 (CODATA 1986), because that is the convention that
underlies the published comparison chain it adjudicates; the value is
carried explicitly in its `c_convention` column. Every other file uses
the CODATA 2018 value above.

| File | Source in the repo | Paper element |
|---|---|---|
| `point_nucleus_table.csv` | `exploration/dirac/ea2_point_table.csv` | Table I |
| `critical_screening_map.csv` | `exploration/dirac/ea3_critical_screening.csv` | Fig. 3 |
| `EA4_convergence.csv` | `results/EA4_convergence.csv` | Fig. 2 |
| `validation_errors.csv` | `exploration/dirac/validation_errors.csv` | Sec. IV |

**Provenance.** The first three files are the **committed production run**
— the same run that produced the figure PDFs shipped next to `main.tex`
and the digits printed in Table I — so the data and the figures cannot
disagree. `validation_errors.csv` is the 2026-08-15 run: the CSV export
was added to `ea1_yukawa_anchors.py` in the packaging pass, so no earlier
machine-readable version of it exists. Re-running the generators
reproduces all four to roundoff (~1e-13 relative), not bit for bit; the
values in the last one or two digits of the roundoff-floor columns
(`rel`, `rel_err`, `dev_f_*`) depend on the LAPACK/BLAS build and are not
themselves meaningful. See `../reproducibility/EXPECTED_OUTPUTS.md`.

## `point_nucleus_table.csv`
Point-nucleus Dirac–Coulomb table (source: `ea2_point_table.csv`,
generated by `ea2_point_table.py`; the manuscript's Table I is a subset).
Z = 92–136, κ ∈ {−1, +1, −2, +2}, lowest three physical states per
channel.

| Column | Meaning |
|---|---|
| `Z`, `kappa` | nuclear charge, relativistic angular quantum number |
| `nu` | Zα |
| `gamma` | √(κ² − (Zα)²) |
| `nr`, `n` | radial and principal quantum numbers |
| `E` | binding energy E − c² (Ha), shifted pencil + exact-summation Rayleigh refinement, N = 45 |
| `rel` | relative deviation from the Sommerfeld formula evaluated in 40-digit arithmetic |
| `drift` | inter-basis drift \|E(N=45) − E(N=30)\| at the chosen β (β selected by minimal drift, never by proximity to the exact value) |
| `beta_fac` | chosen scale factor (β = beta_fac × Z) |
| `nspur` | number of unmatched deep in-gap (spurious) states of the naive κ>0 discretization |
| `spur0` | value of that spurious state (pinned near the ground state of the −κ partner channel; nan if none) |
| `rkb_rel` | relative deviation of the shifted-RKB cross-check (nan where RKB leaves the form domain: γ < 1/2, i.e. \|κ\| = 1, Z ≳ 119) |

## `critical_screening_map.csv`
Relativistic critical-screening map λc(Z, κ) (source:
`ea3_critical_screening.csv`, generated by `ea3_critical_screening.py`;
the manuscript's Fig. 3 plots s_c vs Zα).

| Column | Meaning |
|---|---|
| `Z`, `kappa`, `Zalpha` | as above |
| `lam_c` | critical screening λc |
| `s_c` | reduced critical screening λc/Z |
| `p_threshold` | threshold-law exponent used in the extrapolation (2 for ℓ=0, 1 for ℓ=1) |
| `spread` | convergence spread over two basis sizes × two β scales (honest error bar) |
| `ratio` | s_c divided by the nonrelativistic reference constant of the channel |

Note (as stated in the manuscript): the 1s anchor agrees with the known
nonrelativistic constant to one part in 1e4; the 2p **absolute** values
carry a near-threshold extrapolation uncertainty of a few parts in 1e3,
so the 2p physics is reported through the relative
2p₁/₂–2p₃/₂ splitting, which is far more robust.

## `EA4_convergence.csv`
Convergence data plotted in the manuscript's Fig. 2 (source:
`results/EA4_convergence.csv`, generated by
`ea4_convergence_and_figures.py`). Twenty-four rows: three point-nucleus
states × eight basis sizes. Instrument: γ-basis (μ = γ) + exact cusp
quadrature (`nquad = nb + 150`) + shifted pencil, at the fixed scale
β = 0.9 Z (this file is a convergence sweep in N, so β is *not*
drift-selected here, unlike `point_nucleus_table.csv`).

| Column | Meaning |
|---|---|
| `case` | state label, one of `Z=92,  1s$_{1/2}$`, `Z=92,  2p$_{3/2}$`, `Z=110, 1s$_{1/2}$` (LaTeX math in the label; it is used verbatim as the figure legend entry) |
| `nb` | number of basis functions N per component (8, 10, 12, 15, 20, 25, 30, 40) |
| `dof` | total real degrees of freedom, 2N — the abscissa of Fig. 2, chosen so the comparison with the competing method is on equal footing |
| `rel_err` | \|E − E_exact\| / \|E_exact\|, relative error of the binding energy against the Sommerfeld formula evaluated in 40-digit arithmetic; written at four significant digits (`%.3e`) |

Values at or below ~1e-14 are at the roundoff floor and their digits are
LAPACK/BLAS-build dependent; only the order of magnitude is meaningful
there. That is the point of the figure: the 1s states reach the floor at
2N = 16.

## `validation_errors.csv`
Screened-Coulomb (Yukawa) external validation and adjudication of
Sec. IV (source: `exploration/dirac/validation_errors.csv`, generated by
`ea1_yukawa_anchors.py`). Two rows, one per published anchor case.
**Convention: c = 137.0359895 (CODATA 1986)**, deduced from the residual
patterns of the published chain and then verified independently against
the Krauthauser–Hill 40-digit benchmarks; it is stated in no source
paper. Potential V(r) = −V₀ e^{−λr}/r; the reported invariant is the
dimensionless f = (E − c²)/c², which is what is convention-independent
across the chain.

Case 2 is printed in one source as "V₀ = 0.4c, λ = 0.07c"; that is an
erratum (digits transposed, consistently in prose, table and caption) —
the energy corresponds to V₀ = 0.7c, λ = 0.04c, which is what is used
here and recorded in `label`.

| Column | Meaning |
|---|---|
| `case` | machine-readable identifier, `case1` or `case2` |
| `label` | human-readable case name, including the erratum note for case 2 |
| `V0_over_c`, `lambda_over_c` | the case parameters in units of c: V₀/c and λ/c |
| `c_convention` | the speed of light used, 137.0359895 (CODATA 1986) — see above |
| `Z`, `lam` | the same parameters in Hartree atomic units: Z = V₀, λ |
| `gamma` | cusp exponent √(1 − (V₀/c)²) = the basis prefactor μ |
| `beta` | Laguerre scale β (absolute, not a factor of Z) |
| `nb` | number of basis functions N per component for the quoted values (80) |
| `E_shifted` | binding energy E − c² (Ha) from the **mass-shifted** pencil H − c²S with exactly summed Rayleigh refinement — the value quoted in Sec. IV |
| `f_shifted` | the dimensionless invariant `E_shifted`/c² |
| `dev_f_shifted` | `f_shifted` − `f_KH40`, the signed deviation from the 40-digit benchmark |
| `E_unshifted`, `f_unshifted`, `dev_f_unshifted` | the same three quantities from the unshifted solve that predates the pencil, exported so both are on the record |
| `f_KH40` | Krauthauser–Hill 2002 40-digit reference value of f (via Baye Table VI) |
| `E_ALLSM2026` | the value published by the 2026 adaptive log-orthogonal method (Chen–Shao–Wu) |
| `dev_E_ALLSM` | `E_shifted` − `E_ALLSM2026` (Ha) |
| `E_ref` | the reference row of the published chain: KH via the CSW table (case 1), Baye's Lagrange-mesh value (case 2) |
| `dev_E_ref` | `E_shifted` − `E_ref` (Ha) |
| `published_ALLSM_minus_ref` | `E_ALLSM2026` − `E_ref`, i.e. the discrepancy *between the two published values*, independent of this work — the quantity being adjudicated |
| `E_legendre` | the same binding energy computed with a Gauss–Legendre rule instead of the matched cusp rule, at N = 80 |
| `drift_cusp` | \|E(N=80) − E(N=60)\| with the exact cusp rule, unshifted solve (Ha) |
| `drift_legendre` | \|E(N=80) − E(N=60)\| with Gauss–Legendre (Ha). For case 2 (γ = 0.714) this stalls near 1e-4 while `drift_cusp` reaches ~1e-10: the live demonstration of the exact-quadrature claim of Sec. II |
| `drift_cusp_shifted` | the same cusp-rule drift for the shifted-pencil values |

Sign convention for the `dev_*` columns: computed minus reference, so a
negative entry means the computed level lies below the reference.
